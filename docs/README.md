Всё, что нужно, чтобы менять продукт, не читая код. Каждый файл отвечает на
один вопрос.

| Файл | О чём | Можно править напрямую? |
|---|---|---|
| [product.md](product.md) | Что это за продукт, какие обещания, пять сфер | да |
| [bot-logic.md](bot-logic.md) | Как бот ведёт интервью, по каким правилам решает | да |
| [texts-bot.md](texts-bot.md) | Все реплики бота | **нет** — правится `src/myway/i18n.py` |
| [texts-landing.md](texts-landing.md) | Все тексты лендинга и где их менять | да |
| [sources.md](sources.md) | Библиотека из 28 исследований | **нет** — правится YAML в `corpus/` |
| [sources-review.md](sources-review.md) | Отчёт о проверке этих 28 работ: где формулировка расходится с источником | да |
| [architecture.md](architecture.md) | Файлы, поток данных, стоимость | да |
| [deploy.md](deploy.md) | Запуск бота и лендинга, DNS | да |

Два файла помечены «нет» не из вредности: они собираются из кода командой
`python scripts/build_docs.py`, иначе документация неизбежно разойдётся с тем,
что бот на самом деле говорит и цитирует. Тест `tests/test_docs.py` падает,
если их забыли пересобрать.

## Что где менять — короткая таблица

| Хочу изменить | Файл |
|---|---|
| Реплику бота (приветствие, вопросы, ошибки) | `src/myway/i18n.py` → пересобрать docs |
| Текст на лендинге | `web/index.html` |
| Тон и жёсткость вердикта | `src/myway/coach/prompts.py`, блок `IDENTITY` |
| Формулировку открытого вопроса | `src/myway/i18n.py`, ключ `opening_question` |
| Число уточняющих вопросов | `.env`: `MIN_PROBE_QUESTIONS`, `MAX_PROBE_QUESTIONS` |
| Добавить или убрать исследование | `src/myway/science/corpus/*.yaml` → пересобрать docs |
| Название продукта | `.env`: `PRODUCT_NAME` |
| Модель или её «усердие» | `.env`: `MODEL_DIAGNOSIS`, `EFFORT_DIAGNOSIS` |
| Пять сфер (переименовать) | `src/myway/i18n.py`, `DOMAIN_LABEL` и `DOMAIN_HINT` |
| Слова-триггеры кризисного скрина | `src/myway/safety.py` |

## Как менять безопасно

После любой правки:

```bash
PYTHONPATH=src python -m pytest      # 67+ тестов, ключи и сеть не нужны
python scripts/build_docs.py         # если меняли i18n.py или corpus/
python -m ruff check src tests scripts
```

Что тесты действительно поймают:

- пропавшую подстановку `{product}` в тексте;
- строку, добавленную только на одном языке;
- русский текст, случайно вставленный в английское поле (и наоборот);
- исследование без обязательного поля или с дублирующимся `id`;
- сломанный переход в интервью — есть полный проход от `/begin` до плана;
- незакрытый HTML-тег в тексте бота (экранирование проверяется отдельно).

Чего они **не** поймают: стал ли вердикт лучше или хуже. Это оценивается только
на живых расшифровках — см. [architecture.md](architecture.md#чего-не-хватает).

## Что обязательно сделать до запуска

1. **Проверить 28 исследований.** Все помечены `verified: false` — значит, ни
   одну статью человек ещё не открыл и не подтвердил, что наша формулировка
   честна. Это блокирует запуск. См. [sources.md](sources.md).
   Машинная сверка уже проведена: DOI во всех 28 записях ведут к заявленным
   статьям, но в пяти формулировка расходится с источником и её надо
   переписать до запуска — см. [sources-review.md](sources-review.md).
2. **Подставить имя бота от BotFather** вместо `moyput_bot` в `web/index.html`
   (три места).
3. **Вычитать русские тексты.** Они написаны грамотно, но живым носителем не
   вычитаны — стоит пройтись по [texts-bot.md](texts-bot.md) и лендингу.
4. **Решить, сколько хранить расшифровки** и нужно ли шифрование на диске.
   Сейчас: SQLite без шифрования, удаление по команде `/forget`.
